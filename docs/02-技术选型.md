# 02 · 技术选型

## 1. 选型原则

- 三端（Android / Web / 后端）各用最合适、生态成熟的技术，共用一套 API 契约
- 开发期零配置可跑，生产期可按文档平滑升级
- 生态成熟、招人容易、社区文档丰富

## 2. 移动端：Kotlin + Jetpack Compose（Android 原生）

| 候选 | 结论 | 理由 |
|---|---|---|
| **Kotlin + Jetpack Compose** | ✅ 选用 | 现代 Android 官方 UI 工具包，声明式、状态驱动，与 View 体系相比代码更少、维护成本低；Google 长期主推 |
| uni-app（Vue3） | 备选 | 一套代码多端，但原生体验与性能弱于原生，且多端诉求在 MVP 后并不紧迫 |
| React Native | 备选 | JS 生态，但 Android 原生能力与 Compose 相比仍需桥接层 |
| Flutter | 备选 | UI 一致性强，但与 Android 平台惯例差异大 |

> 移动端工程见 `android/`：单 Activity + Navigation Compose，Retrofit 网络层，Coil 图片加载。

## 3. 网页端：React 18 + Vite + TypeScript

| 候选 | 结论 | 理由 |
|---|---|---|
| **React 18 + Vite + TS** | ✅ 选用 | 生态最大、组件复用强；Vite 开发体验极佳；TS 保证工程健壮 |
| Vue 3 + Vite | 备选 | 语法轻量，但本产品社区方案以 React 更成熟 |
| Next.js | 备选 | 适合 SSR/SEO；本产品为登录后社区，CSR 足够，MVP 更轻 |

配套：**Zustand**（轻量全局状态）、**React Router v6**（路由）、**axios**（拦截器统一注入 token 与 401 处理）、纯 CSS（蓝色主题，不引入重型 UI 库，保持视觉原创）。

## 4. 后端：Java 17 + Spring Boot（JdbcTemplate）

| 候选 | 结论 | 理由 |
|---|---|---|
| **Java 17 + Spring Boot** | ✅ 选用 | 企业级标配：类型安全、生态成熟、高并发能力强；模块化单体结构清晰；JDK17 LTS 长期维护 |
| Node.js + Express | 备选 | 轻量快，但类型与工程化弱于 Java，大规模并发与团队演进不如 Spring 体系 |
| Go | 备选 | 性能好，但业务开发效率与生态（尤其 CRUD/事务）不如 Spring |
| Python FastAPI | 备选 | 开发快，但类型体系与并发场景不匹配 |

关键依赖：

- `spring-boot-starter-jdbc`：JdbcTemplate 数据访问（显式 SQL，避免 ORM 黑盒）
- `spring-boot-starter-webmvc` + Jackson 3：REST API 与 JSON
- `spring-boot-starter-validation`：入参 Bean Validation
- `jjwt 0.12.x`：JWT 签发与解析（HS256）
- `spring-security-crypto`：BCrypt 密码哈希（仅 crypto 模块，不引入整套 Security）
- `h2`（开发）/ `mysql-connector-j`（生产）
- Maven Wrapper：无需预装 Maven 即可构建

## 5. 数据存储

| 数据 | 开发环境 | 生产环境 |
|---|---|---|
| 业务数据 | H2 文件库（`data/xiaolanshu`，MODE=MySQL） | MySQL 8（主从 + 业务分库） |
| 会话/热榜/限流 | 内存（开发） | Redis |
| 图片视频 | 本地 `server/uploads/` | OSS + CDN |
| 搜索 | SQL LIKE | ElasticSearch（演进） |
| 异步通知/计数 | 同步（开发） | 消息队列（演进） |

## 6. 鉴权方案

- **JWT Access Token**（默认 7 天）随请求头携带（`Authorization: Bearer <token>`）。
- 密码 **BCrypt 加盐哈希**存储，绝不存明文。
- 浏览类接口游客可访问（可选登录），互动/发布/私信接口要求登录（`CurrentUser.require`）。

## 7. 部署形态

- 开发：后端 `server: mvnw spring-boot:run`（3000）；网页端 `web: npm run dev`（5173，vite 代理 /api）；Android 在 Android Studio 中运行（模拟器经 `10.0.2.2:3000` 访问宿主机）。
- 生产：Docker Compose 编排（nginx + server 镜像 + mysql + redis），详见 docs/05。
