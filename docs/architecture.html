二、关键业务链路

接口均为 /api 前缀，统一响应 {code, message, data}（code=0 成功）

发布笔记

1客户端选图 → POST /api/upload/image（本地磁盘/OSS 返回 URL）
2POST /api/posts {title, content, images[], topicId}
3事务：写 posts + 话题 post_count+1 + 用户 post_count+1

浏览信息流

1GET /api/feed?tab=recommend|following
2关注流：关注者笔记时间倒序
3推荐流：热度分 score = like×3 + comment×5 + view×0.2
4批量组装作者/话题/登录态互动状态

互动与通知

1点赞/收藏/评论/关注写关系表（UNIQUE 幂等）
2同一事务更新冗余计数
3写入 notifications 供接收者查看

搜索

1GET /api/search?q=&type=all|post|user
2起步：LIKE 匹配标题/正文/昵称
3演进：ElasticSearch 倒排 + 高亮

私信

1conversations（user_a < user_b，UNIQUE）
2GET/POST /api/conversations/{id}/messages 轮询
3演进：WebSocket 长连接 + 已读回执

四、技术栈

三端各取所长，共用 API 契约

Android 端（android/）
  • Kotlin + Jetpack Compose（Material 3）
  • Navigation Compose · 单 Activity
  • Retrofit + OkHttp（自动带 JWT）
  • Coil 图片加载 · ViewModel 状态
  • 模拟器访问宿主机：10.0.2.2:3000
网页端（web/）
  • React 18 + Vite + TypeScript
  • Zustand 全局状态（登录持久化）
  • React Router v6 · axios 拦截器
  • 双列瀑布流 · 蓝色主题（--brand: #1f6fff）
  • dev:5173 代理 /api、/uploads → :3000
后端（server/）
  • Java 17 + Spring Boot（Maven Wrapper）
  • JdbcTemplate 显式 SQL · @Transactional
  • JWT（jjwt）+ BCrypt（spring-security-crypto）
  • Bean Validation · 全局异常 · 内存限流
  • H2 开发（MODE=MySQL）/ MySQL 生产
  • 自动建表 + 演示数据播种
