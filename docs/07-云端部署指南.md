# 07 · 云端部署指南

> 把「小蓝书」三端部署到云服务器的完整操作手册。适用：阿里云 / 腾讯云 / 华为云等任意 Linux 云主机（Ubuntu 22.04 / Debian 12 示例，其他发行版命令大同小异）。
> 共两种方案，任选其一：**方案 A（推荐）** Nginx + systemd 裸机部署，直观易维护；**方案 B** Docker Compose 一键编排（仓库已附配置）。

## 0. 部署形态总览

```
用户（浏览器 / Android App）
        │ HTTPS（推荐）/ HTTP
        ▼
┌── Nginx（公网入口 :80/:443）───────────────────────┐
│  · 静态托管 Web 端构建产物（web/dist）              │
│  · 反向代理 /api、/uploads → 后端 :3000            │
│  · TLS 终止（certbot 免费证书）                    │
└──────────────────────┬────────────────────────────┘
                       ▼
┌── 后端服务（systemd 或 Docker，端口 3000）────────┐
│  · Spring Boot jar（xiaolanshu-server）            │
│  · JWT 签发 + BCrypt + 限流                        │
│  · uploads/ 图片目录（挂载持久卷）                 │
└──────────┬────────────────────┬───────────────────┘
           ▼                    ▼
   MySQL 8（业务库）         Redis（可选，演进）
```

## 1. 前置准备

### 1.1 云服务器选型

| 规模 | 配置建议 | 参考价格（演示/教学） |
|---|---|---|
| 演示 / 课程 / 小流量 | 2C4G，40G 系统盘，按量或轻量应用服务器 | 几十元/月 |
| 正式运营（起步） | 2C4G~4C8G，云盘 80G+，带宽 3~5Mbps | 百余元/月 |
| 高并发（演进） | 见 docs/05，多实例 + 负载均衡 | — |

系统镜像选 **Ubuntu 22.04 LTS** 或 Debian 12（本手册以其命令为例）。购买后记下：**公网 IP**、root 密码/密钥。

### 1.2 域名（可选但推荐）

- 有域名：解析一个 A 记录指向服务器公网 IP（如 `api.xiaolanshu.com → 1.2.3.4`），可免费申请 HTTPS 证书。
- 没域名：直接用 `http://公网IP:3000` 访问后端、`http://公网IP` 访问网页端（App 也指向 IP，开发期可接受）。

### 1.3 安全组 / 防火墙放行（必做）

在云控制台「安全组」及服务器内防火墙（ufw）放行：

| 端口 | 用途 | 建议 |
|---|---|---|
| 80 / 443 | 网站入口 | 放行（必开） |
| 3000 | 后端 API | 开发期临时放行；上了 Nginx 反代后**关掉**（只留内网） |
| 22 | SSH | 放行（建议改密钥登录） |
| 3306（MySQL） | 数据库 | **禁止对外**，仅内网/本机 |
| 6379（Redis） | 缓存 | **禁止对外** |

```bash
sudo apt update && sudo apt install -y ufw
sudo ufw allow 22/tcp && sudo ufw allow 80/tcp && sudo ufw allow 443/tcp
sudo ufw enable
```


### 2.2 网页端 dist

```powershell
cd E:\ProgramData\小蓝书\web

# 产物：web\dist\（整目录上传）
```

### 2.3 Android 安装包（可选，按需打包）

打包在**本地电脑**完成，产物 APK 直接发到手机安装；云端地址通过 Gradle 属性注入，**无需改任何源码**。

#### 2.3.1 需要的工具（缺哪个装哪个）

| 工具 | 版本要求 | 作用 | 获取方式 |
|---|---|---|---|
| JDK | 17 | 编译 Java/Kotlin | oracle.com 或 `winget install EclipseAdoptium.Temurin.17.JDK` |
| Android SDK | Platform 35 + Build Tools 35.0.0 | Android 编译资源与打包 | 随 Android Studio 安装；命令行构建需设 `local.properties` 的 `sdk.dir`（本仓库已写好 `E:\Android\Sdk`） |
| Gradle | 8.14（wrapper 已配好） | 构建引擎 | 无需单独装——用 `gradlew.bat` 自动使用本地缓存 |
| Android Studio | Ladybug 或更新（可选） | 图形化构建/签名/安装调试 | developer.android.com |

> 命令行构建前置：确认 `java -version` 为 17；首次构建会自动下载依赖（网络较慢时耐心等待）。

#### 2.3.2 打包 Debug 包（开发/内部测试，自动 debug 签名，可直接安装）

```powershell
cd E:\ProgramData\小蓝书\android
.\gradlew.bat assembleDebug            # 默认后端地址（本地电脑 192.168.2.6:3000）
.\gradlew.bat assembleDebug -PapiBaseUrl=http://10.0.2.2:3000/   # 指向模拟器宿主机
# 产物：android\app\build\outputs\apk\debug\app-debug.apk
```

#### 2.3.3 打包 Release 包（正式分发/云端用）

**第一步：生成正式签名 keystore（一次性，妥善保管！）**

```powershell
keytool -genkeypair -v -keystore E:\ProgramData\小蓝书\keystore\xls-release.jks `
  -alias xiaolanshu -keyalg RSA -keysize 2048 -validity 36500 `
  -storepass 你的强密码 -keypass 你的强密码 -dname "CN=小蓝书, OU=dev, O=xiaolanshu, L=Chengdu, ST=Sichuan, C=CN"
```

**第二步：指定云端地址并打包（keystore 参数注入，签名自动生效）**

```powershell
# 云端已配置 HTTPS 域名（推荐）：
.\gradlew.bat assembleRelease `
  -PapiBaseUrl=https://api.xiaolanshu.com/ `
  -PkeystorePath=E:\ProgramData\小蓝书\keystore\xls-release.jks `
  -PkeystorePassword=你的强密码 -PkeyAlias=xiaolanshu -PkeyPassword=你的强密码

# 或临时用公网 IP + 端口（开发期验证）：
.\gradlew.bat assembleRelease -PapiBaseUrl=http://1.2.3.4:3000/ `
  -PkeystorePath=E:\ProgramData\小蓝书\keystore\xls-release.jks `
  -PkeystorePassword=你的强密码 -PkeyAlias=xiaolanshu -PkeyPassword=你的强密码
# 产物：android\app\build\outputs\apk\release\app-release.apk
```

> 未传 keystore 参数时，release 包会回退 debug 签名（`app-release.apk` 仍可安装，仅限内部测试）；**正式上架前必须用正式 keystore 重新打包**，否则换签名无法覆盖升级。

**第三步：验证 APK**

```powershell
# 签名校验（打印证书信息即成功）
& E:\Android\Sdk\build-tools\35.0.0\apksigner.bat verify --print-certs `
  android\app\build\outputs\apk\release\app-release.apk
# 包信息
& E:\Android\Sdk\build-tools\35.0.0\aapt.exe dump badging android\app\build\outputs\apk\release\app-release.apk
```

#### 2.3.4 常见问题

- **构建报 "project path contains non-ASCII characters"**：项目在中文路径（`E:\ProgramData\小蓝书`）所致，已通过 `android/gradle.properties` 的 `android.overridePathCheck=true` 解决。
- **APK 连不上后端**：确认地址注入正确（`API_BASE_URL`）、手机与服务器网络可达、服务器防火墙放行对应端口；HTTP 场景需保留 `usesCleartextTraffic="true"`（已默认开启）。
- **更新版本号**：改 `android/app/build.gradle.kts` 的 `versionCode`（每次发布 +1）与 `versionName`。
- **本机无 Android SDK**：Android Studio 装好 SDK 后，确认 `android/local.properties` 的 `sdk.dir` 指向实际路径。

## 4. 方案 A：Nginx + systemd 部署

### 4.1 创建目录并上传产物

```bash
sudo mkdir -p /opt/xiaolanshu/{app,dist,uploads}
```

在**本地电脑**把三个东西传上去（用 scp，或先 `tar` 打包再传）：

```bash
# 本地 PowerShell 执行
scp E:\ProgramData\小蓝书\server\target\xiaolanshu-server-0.0.1-SNAPSHOT.jar root@1.2.3.4:/opt/xiaolanshu/app/
scp -r E:\ProgramData\小蓝书\web\dist\*          root@1.2.3.4:/opt/xiaolanshu/dist/
# 首次部署：把本地 uploads 演示图也带上去（可选，seed 会在服务器重新生成）
scp -r E:\ProgramData\小蓝书\server\uploads\seed root@1.2.3.4:/opt/xiaolanshu/uploads/
```

```bash
# 服务器上设置目录归属
sudo chown -R www-data:www-data /opt/xiaolanshu
```

### 4.2 创建后端 systemd 服务

```bash
sudo tee /etc/systemd/system/xiaolanshu.service > /dev/null <<'EOF'
[Unit]
Description=XiaoLanShu Spring Boot Server
After=network.target mysql.service

[Service]
User=www-data
WorkingDirectory=/opt/xiaolanshu/app
ExecStart=/usr/bin/java -jar /opt/xiaolanshu/app/xiaolanshu-server-0.0.1-SNAPSHOT.jar
Environment=SPRING_DATASOURCE_URL=jdbc:mysql://127.0.0.1:3306/xiaolanshu?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
Environment=SPRING_DATASOURCE_DRIVER_CLASS_NAME=com.mysql.cj.jdbc.Driver
Environment=SPRING_DATASOURCE_USERNAME=xls
Environment=SPRING_DATASOURCE_PASSWORD=你的强密码
Environment=XIAOLANSHU_JWT_SECRET=换成至少32字节的高熵随机串
Environment=XIAOLANSHU_UPLOAD_DIR=/opt/xiaolanshu/uploads
Environment=XIAOLANSHU_WEB_DIST=/opt/xiaolanshu/dist
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF
```

要点（都是 Spring Boot 标准环境变量覆盖 `application.yml`，**无需改任何源码**）：

| 环境变量 | 覆盖的配置 | 说明 |
|---|---|---|
| `SPRING_DATASOURCE_*` | `spring.datasource.*` | 从 H2 切到 MySQL |
| `XIAOLANSHU_JWT_SECRET` | `xiaolanshu.jwt.secret` | 生产必须换成高熵串 |
| `XIAOLANSHU_UPLOAD_DIR` | `xiaolanshu.upload-dir` | 图片目录（持久卷） |
| `XIAOLANSHU_WEB_DIST` | `xiaolanshu.web-dist` | 指向已上传的网页端产物 |

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now xiaolanshu
sudo systemctl status xiaolanshu        # 确认 active (running)
tail -f /var/log/syslog                 # 观察日志（或 journalctl -u xiaolanshu -f）
```

### 4.3 配置 Nginx

复用仓库的 `nginx/nginx.conf`（上传到服务器后微调），或直接写：

```bash
sudo tee /etc/nginx/conf.d/xiaolanshu.conf > /dev/null <<'EOF'
server {
    listen 80;
    server_name api.xiaolanshu.com;   # 改成你的域名；没域名填 _ 用 IP 访问

    root /opt/xiaolanshu/dist;
    gzip on;
    gzip_types text/css application/javascript application/json image/svg+xml;

    location /assets/ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    location /uploads/ {
        alias /opt/xiaolanshu/uploads/;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 60s;
    }

    location / {
        try_files $uri $uri/ /index.html;   # SPA 路由兜底
    }
}
EOF
sudo nginx -t && sudo systemctl reload nginx
```

```bash
curl http://127.0.0.1:3000/api/topics        # code=0
```

## 5. 方案 B：Docker Compose（备用）

仓库已附 `docker-compose.yml` + `server/Dockerfile` + `nginx/nginx.conf`，服务器装好 Docker 后：

```bash
# 服务器安装 Docker
curl -fsSL https://get.docker.com | bash
sudo systemctl enable --now docker

# 上传仓库根目录（含 docker-compose.yml、nginx/、server/、web/dist/）
# 本地先构建好后端镜像所需 jar：
cd E:\ProgramData\小蓝书\server && .\mvnw.cmd -DskipTests package
# 然后上传整个仓库，服务器上：
cd /opt/xiaolanshu-repo
docker compose up -d --build
```

> 用方案 B 前务必修改 `docker-compose.yml` 中的 `XIAOLANSHU_JWT_SECRET`、MySQL 密码等默认值；后端镜像在服务器构建（`docker build ./server`），`web/dist` 由 nginx 卷挂载。

## 6. 上线前安全清单（必读）

> 状态说明：✅=代码层已落地（v2.1.0）；⬜=需在云服务器/域名上手动执行。代码层实现均支持环境变量注入，云端部署时按说明替换即可。

- [✅] **JWT 密钥**：代码已改为环境变量注入 `XIAOLANSHU_JWT_SECRET`，启动时校验：密钥 <32 字节或仍为仓库默认值会打 `[security]` WARN 告警。**上线前**：`openssl rand -base64 48` 生成随机串后注入环境变量（docker-compose 已预留该项，将 change-me 占位替换）。
- [✅] **管理接口保护**：`/api/admin/*` 全部要求请求头 `X-Admin-Key`，密钥经 `XIAOLANSHU_ADMIN_KEY` 注入（默认 dev-admin-key，上线必须替换）。无密钥返回 403。
- [✅] **验证码防爆破**：同一手机号连续 5 次验证失败锁定 5 分钟（发送与校验均被拒绝，429）；60 秒发送间隔；验证码 TTL 5 分钟、一次性。
- [✅] **限流**：默认每 IP 每分钟 300 次，已支持 `XIAOLANSHU_RATE_LIMIT_MAX_PER_MINUTE` 环境变量调整（docker-compose 已预留）；被刷可再加 Nginx `limit_req`。
- [✅] **合规-内容审核**：发布/编辑/评论统一过敏感词机审（`xiaolanshu.audit.enabled`），命中拦截并记审核日志（管理接口可查）。
- [✅] **合规-隐私政策/用户协议**：Web 端已上线 `/privacy`、`/terms` 静态页，登录/注册页底部已加协议链接；Android 登录页已加「登录/注册即代表同意」提示。
- [⬜] **MySQL 密码**：部署时设置强密码 + 仅 localhost 访问；3306 不对公网（见 docker-compose 注释与第 5 节）。
- [⬜] **关闭后端公网直连**：Nginx 反代生效后，安全组关闭 3000 对公网。
- [⬜] **HTTPS**（强烈推荐）：域名解析后执行 `sudo apt install -y certbot python3-certbot-nginx && sudo certbot --nginx -d api.xiaolanshu.com`，自动签发续期；之后 App 改用 `https://` 并移除 `usesCleartextTraffic`。
- [⬜] **SSH 安全**：改用密钥登录，禁用 root 密码登录（`/etc/ssh/sshd_config` 中 `PasswordAuthentication no`）。
- [⬜] **备份**：MySQL 定时备份（见第 7 节）。

### 7.1 日志

```bash
journalctl -u xiaolanshu -f                  # 实时看后端日志
journalctl -u xiaolanshu --since "1 hour ago" # 最近一小时
```

```bash
sudo systemctl restart xiaolanshu            # 重启后端
# 升级后端：上传新 jar 到 /opt/xiaolanshu/app/ 后 restart 即可
# 升级网页端：上传新 dist 内容到 /opt/xiaolanshu/dist/，nginx 无需重启（静态文件）
```

### 7.3 数据库备份与恢复

```bash
# 每日 2:30 备份（crontab -e）
30 2 * * * mysqldump -u xls -p'密码' xiaolanshu | gzip > /backup/xls_$(date +\%F).sql.gz

# 恢复
gunzip < /backup/xls_2026-09-28.sql.gz | mysql -u xls -p'密码' xiaolanshu
```

### 7.4 上传目录与磁盘

- 图片在 `/opt/xiaolanshu/uploads/`（自动按需新建）；注意磁盘水位，建议把 uploads 挂到云盘或对象存储（演进见 docs/05）。
- 服务器监控：`df -h` 看磁盘，`htop` 看资源；云平台自带监控告警建议开启。

## 8. 云端与本地代码差异一览（对照表）

| 项 | 本地电脑做服务器 | 云端服务器 |
|---|---|---|
| Android 地址 | `-PapiBaseUrl=http://电脑局域网IP:3000/`（默认已配） | `-PapiBaseUrl=https://域名/` 或 `http://公网IP:3000/` |
| 后端数据源 | H2 文件库（默认） | MySQL 8（环境变量 `SPRING_DATASOURCE_*`） |
| JWT 密钥 | 开发默认值 | 必须换高熵（`XIAOLANSHU_JWT_SECRET`） |
| 网页端访问 | dev 5173（已开局域网）或后端同端口托管 | Nginx 托管 `dist` + 反代 |
| 图片存储 | `server/uploads/` 本地 | `/opt/xiaolanshu/uploads/`（或 OSS） |
| HTTPS | 不需要 | 推荐（certbot） |
| 防火墙 | Windows 放行 3000 | 安全组放行 80/443，3000 仅内网 |
